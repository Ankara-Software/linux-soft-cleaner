🧹 linux-soft-cleaner
GitHub →

Safe server disk cleanup,
written in Rust.

Reclaim gigabytes of disk space on Linux servers with age-gated file filtering and mandatory dry-run previewing.

linux-soft-cleaner --dry-run --days 7

🛡️ Safe by Default

Preview exact deletions with --dry-run before modifying a single file on disk.

⏱️ Age Threshold Filter

Configurable age filter (--days 7) ensures recent logs and temp files are never touched.

🐳 Docker & NPM Support

Optionally prune unused Docker images/containers and clear global NPM package caches.

📦 APT / DNF / Pacman Caches

Cleans stale package manager archives across Ubuntu, Debian, CentOS, RHEL, and Arch Linux.
